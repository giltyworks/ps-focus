## What's new

Changes since **1.1.25**:

- **Close means exit.** The X now closes PS Focus completely. Minimise hides it in the tray, where it keeps counting, and Start minimized opens it there.
- **Starts solid.** A new install starts fully opaque; set see-through from the transparency icon whenever you like.
- **An Update button.** When a new version is out, Settings shows an Update button; hover it to see the version.
- **Instant tooltips.** Tooltips now show as soon as you point at something.
- **Feedback, tidied.** The feedback stars match the rating stars, and Got feedback? stands out in Settings.
- **Fixes:** the Feedback window's title bar is dark again, small windows open on the same screen as PS Focus, and the rating window keeps a sensible width in landscape.

## Install

Download **PS-Focus-Setup-1.1.26.exe** below and run it. It updates an existing install and keeps your history, settings and Google sign-in.

The app isn't code-signed yet, so you may see warnings. Your browser may say the file isn't commonly downloaded: choose to keep it (in Edge, **⋯** › **Keep** › **Keep anyway**). Then Windows may say "Windows protected your PC": choose **More info**, then **Run anyway**.
