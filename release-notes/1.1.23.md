## What's new

A quick fix to **1.1.22**:

- **Friend details no longer freeze the app.** Double-clicking a friend's name now opens their figures in a small popup under the name, closed by any click, instead of a separate window that could leave PS Focus unresponsive.

Also in 1.1.22, if you skipped it: a transparency slider beside the module icons, a proper scroll bar for Friends, and a fix for the window squashing narrow in landscape.

## Install

Download **PS-Focus-Setup-1.1.23.exe** below and run it. It updates an existing install and keeps your history, settings and Google sign-in.

Windows may say "Windows protected your PC" because the app isn't code-signed yet: choose **More info**, then **Run anyway**.
