## What's new

Changes since **1.1.26**:

- **Goal pulse and levels.** The header pulses when you reach your daily goal. Levels now show XP and a level-up popup, and the top levels are harder to reach, so a long-time user's level may drop a little.
- **Two PCs, one account.** Each PC's time is now kept apart when Google Drive backups are merged, so time in the same hour on two PCs adds up instead of one overwriting the other. An hour held both ways counts the larger copy. Update every PC together.
- **Safer shutdown.** Time not yet saved when PS Focus closes is kept and added on the next start, and double counting between old and new PCs is fixed.
- **Smooth resizing.** Dragging the window's edge no longer stutters, which was most noticeable on large, fast screens, and the window stays solid while you drag it.
- **Instant fade.** With see-through on, the window turns solid the moment the mouse touches it from any side, not up to a second later.
- **Tighter layout.** The gaps between blocks are 2 pixels instead of 4.
- **Fixes:** double-clicking a rating star no longer clears it, session counts and streaks use one shared minimum, and "Remaining XP" can no longer show 0 before the level rises.

## Install

Download **PS-Focus-Setup-1.1.27.exe** below and run it. It updates an existing install and keeps your history, settings and Google sign-in.

The app isn't code-signed yet, so you may see two warnings:

- If your browser says the file isn't commonly downloaded, keep it. In Edge, choose **⋯**, then **Keep**, then **Keep anyway**.
- If Windows says "Windows protected your PC", choose **More info**, then **Run anyway**.
