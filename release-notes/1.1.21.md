## What's new

Changes since **1.1.0**:

- **Draw with friends.** Add friends by code to see each other's levels, hours and who's drawing right now. Show yourself as Online, Away, Invisible or Offline, and keep favourites and nicknames.
- **PhotoCraft.** Now tracked alongside Photoshop, Krita and Clip Studio Paint.
- **One Today panel.** It follows the program you're drawing in; its arrow shows another program's history.
- **Smoother docking.** Panels snap, slide and move together more reliably.
- **Clearer see-through panels.** Backgrounds fade while text stays solid and readable.
- **More reliable tracking**, including across midnight, sleep and a locked screen.
- **Try it online.** An interactive demo on the website.
- **Also:** a more compact layout, a custom title bar, and many small tidy-ups.

## Install

Download **PS-Focus-Setup-1.1.21.exe** below and run it. It updates an existing install and keeps your history, settings and Google sign-in.

Windows may say "Windows protected your PC" because the app isn't code-signed yet: choose **More info**, then **Run anyway**.
