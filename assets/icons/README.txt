PS Focus icon pack

The logo is a soft white disc (#F4F4F4) holding one thick near-black stroke (#080808) with rounded ends.
It rises from low on the left, turns a rounded corner, crosses the top and curves down the right, so the
white it encloses reads as a lowercase p (the "hidden p" design). The mark is turned 15 degrees
anticlockwise to centre the p, and trimmed so the white rim is equally wide all the way round. An earlier
design, a plain arc like a progress ring, is kept in the script on standby (DESIGN = "arc").

Every file here is drawn by make_icons.py from the measurements at its top; change those and rerun it
rather than editing the images:

    py assets/icons/make_icons.py

Each size is drawn separately, eight times larger and then reduced, so small icons stay crisp.

Files:
- PSFocus_Master_1024.png: the logo at full size
- PNG sizes: 512, 256, 128, 64, 48, 32, 24, 20, 16
- PSFocus.ico: the Windows icon, holding each size from 16 to 256; used for the program, shortcuts,
  taskbar, title bar and installer
- PSFocus_AppWindow_16.png, PSFocus_AppWindow_32.png: title-bar icons
- PSFocus_Taskbar_48.png: taskbar icon
- PSFocus_Settings_64.png: tray icon
- PSFocus_Preview_LightDark.png, PSFocus_Preview_Sizes.png: previews for checking the logo

The logo was redesigned on 3 October 2026; the black-and-white logo before it remains in Git history.
