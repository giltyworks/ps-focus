# PS Focus

## What it is
A Windows desktop app that counts time while Photoshop, Krita, Clip Studio Paint or PhotoCraft owns the visible
foreground window. It keeps totals in a local SQLite database, shows Today, chart, calendar, Stats and Friends
blocks (which can be docked or floated), awards levels, writes rotating local backups, and can optionally sync
settings and an activity backup to the user's private Google Drive app-data folder. It's GPL v3 and published at
github.com/giltyworks/ps-focus. README.md describes all of this in detail.

## Tech stack
- Python 3.14 on Windows; UI in Qt via `PySide6_Essentials==6.11.2`; PyInstaller and its hooks are pinned in requirements.txt too, since the release build needs them
- Windows APIs through `ctypes` (foreground detection, DPAPI, WinHTTP in `web.py`, so there's no OpenSSL)
- PyInstaller 6.22.3 (`PS Focus.spec`) and Inno Setup 6 (`installer/PS Focus.iss`) for the release build
- Friends server: Cloudflare Worker + D1 (`friends_server/`, JS, wrangler). Feedback/update check: Google Apps Script (`feedback_endpoint/Code.gs`)
- Website: GitHub Pages / Jekyll in `docs/`, with an interactive JS demo in `docs/assets/demo/`

## Commands (PowerShell, from the project root)
- Install: `py -m pip install -r requirements.txt`
- Run: `py -m qt` (works on a fresh copy of the data in `%APPDATA%\PS Focus Qt Preview`)
  - `--real-data` uses the real data folder; `--dev` opens the developer version; `--uninstall` opens the uninstall window
- Test: `py -m unittest discover`
  - If tests fail, rerun only the failing tests with -v for detail
- Build: `py tools/build_release.py` (runs the tests, PyInstaller, credential checks, smoke test, installer and checksums; output goes to `dist/installer/`)
- See the UI without opening the app: `py tools/ui_screenshots.py before`, make the change, then `py tools/ui_screenshots.py after` (PNGs in the git-ignored `screenshots/`: each block, both window layouts, and side-by-side `compare/`; made-up data only, `--scale 1.5` for a scaled display)
- Credential scan (also runs in CI on every push): `py tools/check_credentials.py`
- Friends server locally: `cd friends_server; npm run dev`, then `py test_server.py`
- After editing PRIVACY.md or TERMS.md: `py tools/sync_site.py`

## Layout
- `qt/`: the app. `__main__.py` is the entry point, `app.py` holds the tracking loop, tray, backups and updates, `window.py` does the layout, and there's one file per block (`today_panel.py`, `chart.py`, `calendar_module.py`, `stats_module.py`, `friends_module.py`). `theme.py` has colours and fonts; `module.py` has the shared painting
- Root `.py`: non-UI logic: `tracker.py` (database and detection), `app_config.py` (paths, constants, defaults, `APP_VERSION`), `google_drive.py`, `friends.py`, `feedback.py`, `update_check.py`, `uninstall.py`, `windows_startup.py`, `stat_lines.py`
- `test_*.py`: unittest suites at the root. `tools/`: build, release and site scripts. `assets/`: icons and sounds (generated by `make_*.py` scripts)
- `docs/`: the website. `release-notes/`: notes for each version. `installer/`: Inno Setup script
- `HANDOVER.md` is shared between you and another AI tool. Read it before starting work, and at the end of each session update it with what changed, what's next, and any open questions, so the other tool can pick up where you left off. `CODE_REVIEW.md` and `TRACKING_REVIEW.md` are that tool's review notes

## Conventions seen in the code
- Every module opens with a docstring saying what it is; `from __future__ import annotations`; type hints on functions
- Comments are plain-English sentences explaining *why*, usually without a final full stop. Names are full words (`application`, `temporary`), not abbreviations
- Qt blocks paint themselves (`paintEvent` + `QPainter`) rather than building from stock widgets. Measurements are named module-level constants
- Tests use `unittest` only and set `QT_QPA_PLATFORM=offscreen`. They patch `app_config` paths onto a `TemporaryDirectory` so they never touch real data, and skip if PySide6 is missing
- Stay on `PySide6_Essentials`. Before using OpenGL, SVG, Qt networking or similar, check `excludes`/`needed_file` in `PS Focus.spec`
- Never commit credentials (`credentials.json`, tokens, keys); CI and the build both scan for them
- Commit messages: one short subject line
- Don't change layout, colours or visual design without asking me first
